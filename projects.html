DIGITAL DESIGN / REVERSIBLE LOGIC

Design and Implementation of a
4×4 Reversible Multiplier

01 — THE CHALLENGE

Problem Statement

Traditional irreversible circuits generate heat and consume more power due to information loss during computation. There is a need for low-power arithmetic circuits with reduced quantum cost and hardware complexity.

02 — THE APPROACH

Solution

Design reversible arithmetic modules using HNG, Peres, Feynman, and other reversible gates through RTL design. Implement and simulate a 4×4 reversible multiplier in Verilog HDL using Xilinx Vivado.

HNG Peres Feynman Other reversible gates

03 — IMPLEMENTATION

Technologies Used

  • Verilog HDL
  • RTL Design
  • Xilinx Vivado
  • FPGA Technology
